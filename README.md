# Cosmic Explorer Location Search (CELS)
This python package contains code to assist with identifying and evaluating
potential locations for [Cosmic Explorer](https://cosmicexplorer.org), a planned
next-generation gravitational-wave observatory.

## Disclaimer
***Example candidate layouts evaluated using this package are based solely on geographical information. 
No decision has been 
made on Cosmic Explorer locations. Observatory locations and configurations will be co-developed in 
consultation with local and Indigenous communities. Any future decision to build will follow established 
protocols, including NEPA and NHPA processes, 
and will involve representatives from relevant federal agencies, the National Science Foundation, local governments,
Native Nations, and ancestral stewards.***

## Installation
To install this code in your python environment, you can run the 
following terminal command:
```sh
pip install -e .
```

## Usage
The following is an example of a command to run a search for potential
detector locations on two threads. In the terminal, navigate to the
top level directory of the CosmicExplorerLocationSearch repository, and 
then do the following commands:
```sh
mkdir test_search
findsites \
  --lon=-107.7 --lat=32.3 --width=100000.0 --height=40000.0 \
  --N=10 --arm_length=40000.0 --dl=1000.0 --opening-angle=90.0 \
  --rotation-angles=18 \
  --elevation=./tests/test_images/SouthNM_Elevation_1km.tif \
  --landcover=./tests/test_images/SouthNM_Landcover_1km.tif \
  --roads=./tests/test_images/SouthNM_Roads_1km.shp \
  --outscore=200.0 --outdir=./test_search/ --njobs=2
```
This command will output the following:
* geotiff images containing the best score at each vertex location
* shapefiles with the detectors with scores below the threshold `outscore`
* a csv file with scores of all configurations tested during the search

For help on the available options, run
```sh
findsites -h
```

Individual functions can also be used directly in python through
the following modules:
```python
from CosmicExplorerLocationSearch import Coordinates, Detector, Geotiff, Score
```
* `Coordinates`: utilities for converting longitude, latitude to x,y coordinates
in different projections
* `Detector`: a function `detector()` that creates a detector configuration,
represented as an an "L" shape determined by the locations of two end stations
and a vertex
* `Score`: functions to evaluate (score) detector configurations, using e.g.
elevation and landcover data

For help on an individual function, use Python's `help()` command to show
available commands and their documentation:
```python
import CosmicExplorerLocationSearch
help(CosmicExplorerLocationSearch)
from CosmicExplorerLocationSearch import Coordinates, Detector, Geotiff, Score
help(Coordinates)
help(Detector)
help(Geotiff)
help(Score)
```

## Generating a shapefile of detectors with the best scores for a given area

This command is run on the results of an existing search, and requires an ordered scores output file from FindSites and a shapefile for an arbitrary zone or state boundaries. A link to a state boundaries shapefile is below in [Data](#data) - these are only needed when running a search on a state.

The scores.csv output file generated by FindSites needs to be ordered by total score in order to perform the search. This can be done with the sort shell command:

```sh
sort -t ' ' -k9n scores.csv > ordered_scores.csv
```

The sorting only needs to be done once for each scores.csv file, not every time the script is run.

To generate a shapefile for detectors with a total score below 80 in the state of Texas:

```sh
mkdir Texas
getmoreLs \
 --state='Texas' \
 --threshold=80 \
 --scores_csv='ordered_scores.csv' \
 --shapefile='gz_2010_us_040_00_500k/gz_2010_us_040_00_500k.shp' \
 --outdir_path='Texas'
```

For a similar search in an arbitrary zone of interest we name "AreaOfInterest":

```sh
mkdir LsInAreaOfInterest
getmoreLs \
 --blob='AreaOfInterest' \
 --threshold=80 \
 --scores_csv='ordered_scores.csv' \
 --shapefile='AreaOfInterest.shp' \
 --outdir_path='LsInAreaOfInterest'
```

For a national search: 


```sh
mkdir National
getmoreLs \
 --threshold=80 \
 --scores_csv='ordered_scores.csv' \
 --outdir_path='National' \
 --arm_length_meters=38000.0 \
 --dl_arms_meters=100.0
```


## Data
The code requires geotiffs with elevation and landcover data for the United
States. Small, public-domain test images are included in the repository. 
Sources of national data include the following:
* [100-meter elevation data (2012)](https://earthworks.stanford.edu/catalog/stanford-zz186ss2071)
* [100-meter landcover data (2001)](https://purl.stanford.edu/wv372bn9329)
* [30-meter landcover data (2021)](https://www.mrlc.gov/data/nlcd-2021-land-cover-conus)
* [State boundaries shapefile (2010)](https://www2.census.gov/geo/tiger/GENZ2010/gz_2010_us_040_00_500k.zip)
* [Primary roads data (2024)](https://www.census.gov/cgi-bin/geo/shapefiles/index.php?year=2024&layergroup=Roads)
